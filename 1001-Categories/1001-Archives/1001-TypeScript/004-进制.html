# 进制

# 有符号整数类型：

类型 占用存储空间 占位
int8 1byte 1 * 8 = 8位
int16 2byte 2 * 8 = 16位
int32 4byte 4 * 8 = 32位
int64 8byte 6 * 8 = 64位

# 无符号整数类型:

类型 占用存储空间 占位
uint8 1byte 1 * 8 = 8位
uint16 2byte 2 * 8 = 16位
uint32 4byte 4 * 8 = 32位
uint64 8byte 6 * 8 = 64位

# 进制转换

二进制每一位对应的十进制 = 位数对应的值 * 2^(位数 - 1)；比如：10 = 1 * 2^(2-1) + 0 * 2^(1-1) = 2

# 整数值的范围 - 以占用空间1byte的整数为例:

# 无符号uint8：1byte即8位，因此最大数二进制表示为:

8位 7位 6位 5位 4位 3位 2位 1位
1 1 1 1 1 1 1 1
1 * 2^7 1 * 2^6 1 * 2^5 1 * 2^4 1 * 2^3 1 * 2^2 1 * 2^1 1 * 2^0
128 64 32 16 8 4 2 1
// uint8可以表示的最大十进制值为:
var uint8MaxNum = 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255

# 有符号int8：1byte即8位，因此最大数二进制表示为:

有符号二进制最高位表示符号： 0表示正数，1表示负数

  • 因此int8最小值为： 10000000
  • 因此int8最大值为： 01111111
# 正数
8位 7位 6位 5位 4位 3位 2位 1位
0 1 1 1 1 1 1 1
正号+ 1 * 2^6 1 * 2^5 1 * 2^4 1 * 2^3 1 * 2^2 1 * 2^1 1 * 2^0
0 64 32 16 8 4 2 1
// uint8可以表示的最大十进制为:
var int8MaxNum = (64 + 32 + 16 + 8 + 4 + 2 + 1) = 127
